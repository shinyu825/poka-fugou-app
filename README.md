# ポカ富豪

ポーカーと大富豪を組み合わせたオリジナルのトランプゲームアプリです。
最初にポーカーで勝負し、その手札のまま大富豪を行い、合計ポイントで順位を決めます。
Flutter で作成しています。

## 準備

- トランプ 1 デッキ(ジョーカーなし 52 枚)を使用
- プレイヤーは自分を含めて 2 人
- 自分以外は CPU

## 今後の対応予定

- ジョーカーの追加(ポーカーではワイルドカード、大富豪では最強カードとして扱う予定)
- プレイヤー人数の追加
- オンライン対戦

## ゲームの流れ

1. ポーカー
2. 大富豪(ポーカーの手札をそのまま使用)
3. 2 つの合計ポイントで順位を決定

山札は 1 ゲームを通して共通で、交換や捨て札で手放したカードは山札に戻りません。

山札の残り枚数の例(2 人プレイ):

| タイミング | 残り枚数 |
| --- | --- |
| デッキ生成 | 52 |
| ポーカーで 5 枚ずつ配る | 42 |
| 自分 2 枚・相手 3 枚交換 | 37 |
| 大富豪で 2 枚ずつ引く | 33 |

## ポーカーのルール

- 各プレイヤーに 5 枚ずつ配る
- 交換したいカードを選んで捨て、捨てた枚数分を山札から引く(交換は 1 回のみ。交換しなくてもよい)
- その 5 枚で役の強さを比べる

役の強さと勝ったときのポイント:

| 役 | ポイント |
| --- | --- |
| 役なし(ハイカード) | 1 |
| ワンペア | 1 |
| ツーペア | 2 |
| スリーカード | 3 |
| ストレート | 4 |
| フラッシュ | 5 |
| フルハウス | 6 |
| フォーカード | 7 |
| ストレートフラッシュ | 8 |
| ロイヤルフラッシュ | 9 |

- 役がない場合は、手札で一番強いカード(A > K > Q > J > 10 > 9 ...)を持つプレイヤーの勝ち(ポイントは 1 点)
- 役の強さが同じ場合は、山札から 1 枚ずつ引き、強いカード(A > K > Q > ... > 3 > 2)を引いたほうの勝ち。決着がつくまで引き続ける
- 1 位のプレイヤーは役のポイント分プラス、最下位のプレイヤーは同じ分マイナス。中間順位は増減なし

例(4 人の場合):

| プレイヤー | 役 | 結果 |
| --- | --- | --- |
| A | スリーカード | +3 |
| B | ワンペア(KK) | 0 |
| C | ツーペア | 0 |
| D | ワンペア(JJ) | -3 |

## 大富豪のルール

ポーカーの手札はそのままに、山札から各自 2 枚引いて 7 枚にしてから始めます。
基本は通常の大富豪と同じです。

### 基本ルール

- ダイヤの 3 を持っている人から時計回り(誰も持っていない場合はランダムに決める)
- 階段なし
- 革命あり
- 縛り・数縛り・激縛りあり
- 禁止あがりあり(2・8 で上がるのは禁止。革命中は 3・8)

### カードの効果

6 の効果はこのゲーム独自のルールです。

| カード | 効果 |
| --- | --- |
| 5 | スキップ: 出した枚数分、プレイヤーを飛ばす |
| 6 | ドロー(オリジナル): 出した本人が、出した枚数分、山札からカードを引く |
| 7 | 渡し: 出した枚数まで、次のプレイヤーに手札からカードを渡せる |
| 8 | 切り: 場が流れ、出した人からもう一度始める |
| 10 | 捨て: 出した枚数まで、手札からカードを捨てられる |
| J | バック: 場が流れるまで強さの順が逆になる |
| Q | ボンバー: 出した枚数分の数字を選び、その数字のカードを持つプレイヤーはそのカードを捨てる(Q は選択不可) |

### ポイント

- 最後まで残ったプレイヤーの手札の枚数分、1 位はプラス、最下位はマイナス
- 革命が起きた回数に応じてポイントが倍になる(1 回で 2 倍、2 回で 3 倍、3 回で 4 倍...)

例(4 人の場合、革命なし):

| プレイヤー | 順位 | 結果 |
| --- | --- | --- |
| A | 1 位 | +2 |
| B | 2 位 | 0 |
| C | 4 位(手札 2 枚残り) | -2 |
| D | 3 位 | 0 |

革命が 1 回あった場合は A が +4、C が -4 になります。

## 最終結果

ポーカーと大富豪の合計ポイントで順位を決めます。

上の例の場合:

| プレイヤー | ポーカー | 大富豪 | 合計 | 順位 |
| --- | --- | --- | --- | --- |
| A | +3 | +2 | +5 | 1 位 |
| B | 0 | 0 | 0 | 2 位 |
| C | 0 | -2 | -2 | 3 位 |
| D | -3 | 0 | -3 | 4 位 |

## 技術構成

- Flutter / Dart
- 状態管理: provider
- 通信: dio
- トランプのデッキ・画像: [Deck of Cards API](https://deckofcardsapi.com/)

## ディレクトリ構成

```
lib/
├── constants/    定数・文言
├── models/       役判定、AI、API レスポンス
├── repository/   API 通信
├── view_models/  画面ロジック
└── views/        画面・UI 部品
```

## セットアップ

```bash
flutter pub get
flutter run
```

iOS 実機で動かす場合は、Xcode の Signing & Capabilities で自分の Team を選択してください。
